# Faceless Agent

Faceless Agent is a personal automation tool. Its owner uses it to upload videos to their own YouTube channel. It is not offered to the public.

- It asks for one Google permission only: **upload videos to YouTube** (`youtube.upload`).
- It does not read email, contacts, Drive or any other account data.
- Sign-in tokens stay on the owner's computer.
