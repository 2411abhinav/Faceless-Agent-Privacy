# Privacy Policy – Faceless Agent

_Last updated: 30 October 2026_

Faceless Agent is a personal automation tool used by its owner to upload videos to the owner's own YouTube channel. It is not offered to the public.

## What data it accesses
- **YouTube account (OAuth scope `youtube.upload`)**: used only to upload videos, titles, descriptions, tags and thumbnails to the signed-in user's own channel.
- No other Google account data (email, contacts, Drive, Gmail and so on) is requested or read.

## How data is stored
- The OAuth sign-in token is stored locally on the owner's computer in `token.json`. It is never committed to source control or sent to any other server.
- Generated videos, scripts and logs stay on the owner's computer.

## Sharing
No user data is sold, shared or transferred to third parties. Video content is sent only to YouTube, as part of the upload.

## Use of Google user data
Faceless Agent's use of information received from Google APIs complies with the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Revoking access
You can revoke access at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions), and delete the local `token.json` file.
